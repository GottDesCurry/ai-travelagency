# Projektüberblick

AI TravelAgency ist eine KI-gestützte Reiseplattform. Kunden beschreiben ihre Reise in natürlicher Sprache oder füllen ein Formular aus; die Plattform sucht echte Flug- und Hotelangebote, vergleicht sie und hebt die besten hervor. Gebucht und bezahlt wird beim Anbieter.

Mehrwert gegenüber klassischen Vergleichsportalen: personalisierte, nachvollziehbare Auswahl durch KI, ohne dass Preise oder Angebote erfunden werden.

- Repo: GottDesCurry/ai-travelagency
- Stack: Next.js 15, React 19, TypeScript, Tailwind 4, OpenAI, RapidAPI (Booking), Vercel
