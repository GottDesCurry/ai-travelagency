# Blue aviation visuals

Generated for Book Repeat with the built-in image generation tool on 14 October 2026.

- aircraft-blue.webp: unbranded white passenger jet with navy tail, cool lighting, front-left three-quarter view, nose right, transparent alpha.
- cloudscape-blue.webp: detailed high-altitude cumulus cloudscape, blue sky and cyan light, no aircraft or text.

The homepage and intro use these same original images. The intro is a camera pullback from close detail to a wide view, with different depth rates for aircraft, sky and foreground clouds. It is an image-based camera effect, not video generation, recorded footage or a fully animated 3D aircraft. The earlier orange stock-video assets have been removed from the active site.

Original compositions and aircraft alpha are preserved. WebP delivery reduces file size. Skip/Escape, reduced motion, Data Saver, first visit per tab, missing-asset timeout and focus restoration remain available.
