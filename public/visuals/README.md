# Blue aviation visuals

Generated for Book Repeat with the built-in image generation tool on 14 October 2026.

- aircraft-blue.webp: unbranded white passenger jet with navy tail, cool lighting, front-left three-quarter view, nose right, transparent alpha.
- cloudscape-blue.webp: detailed high-altitude cumulus cloudscape, blue sky and cyan light, no aircraft or text.

The homepage and intro use these same original images. Since 27 November 2026 the intro is a flight pass: the jet climbs out of the clouds on the left, flies towards the camera with a slight bank and turbulence, and sweeps past on the right, while three cloud layers stream by at different speeds and contrails fade in. It is a CSS transform animation of the still images (no video, no 3D model, no extra downloads).

Skip/Escape, reduced motion, Data Saver, slow connections, first visit per tab, missing-asset timeout and focus restoration remain available.
