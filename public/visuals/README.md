# Blue aviation visuals

Generated for Book Repeat using the built-in image generation tool on 14 October 2026.

- aircraft-blue.webp: unbranded, photorealistic white passenger jet with navy tail, cool blue lighting, front-left three-quarter view, nose to the right, transparent background.
- cloudscape-blue.webp: photorealistic high-altitude cumulus cloudscape, blue sky and cyan light, open center, no aircraft or text.

Source PNGs were converted to WebP for delivery without changing the composition; aircraft alpha is preserved. These are illustrative generated assets, not photos of a particular flight or carrier. The intro uses CSS image-layer animation, not a prerecorded video or 3D flight simulation. Asset failure, reduced motion and Data Saver skip the intro. Only first homepage entry per tab plays it.
